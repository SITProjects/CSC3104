Webhooks

When a job ends we POST its id and status to your webhook URL. A delivery that does not get a 2xx answer is retried a few times. Each request carries X-Idlecloud-Timestamp and X-Idlecloud-Signature: the hex HMAC-SHA256 of <timestamp>.<raw body>, keyed with your signing secret (shown when you create an API key). Ignore a timestamp more than 5 minutes old.

Endpoints

POST /api/jobsUpload a PDF (multipart field pdf, optional webhook_url)
GET /api/jobsYour jobs, newest first
GET /api/jobs/{id}Status and progress of one job
POST /api/jobs/{id}/cancelStop a job
GET /api/jobs/{id}/resultThe OCR text once the job is COMPLETED

Example

curl -H "X-API-Key: $KEY" -F pdf=@scan.pdf {{ request.base_url }}api/jobs
curl -H "X-API-Key: $KEY" {{ request.base_url }}api/jobs/JOB_ID
