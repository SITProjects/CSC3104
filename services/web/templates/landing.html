How it works

  1. {{ icon("upload", "size-4") }}

    1. Submit a job

    Upload a PDF for text recognition, or send a Python or PyTorch script with its files.

  2. {{ icon("cpu", "size-4") }}

    2. Idle PCs run it

    The work is split into tasks that run on campus PCs while they are idle. If a PC is taken back, its task moves to another one.

  3. {{ icon("shield-check", "size-4") }}

    3. Results are verified

    Copies of a task are compared and spot-checked before its result counts. Then you download it.

{{ icon("activity", "size-4") }} Live progress

Follow every task, the PC running it and the vote as it happens.

{{ icon("server", "size-4") }} Extra capacity

When the campus is busy, cloud workers are added so your job still finishes.

{{ icon("download", "size-4") }} Simple results

Download the recognised text, or your script's output folder and log.
